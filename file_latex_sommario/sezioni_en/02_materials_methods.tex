\section{Materials and methods}

\subsection{Shor's algorithm, validation, and definition of success}\label{sec:implementation-en}

For a base \(a\) coprime to the number \(N\) to be factored, the sequence
\(a^{x} \bmod N\) is periodic; its period, called the order \(r\), is the smallest
positive integer such that \(a^{r} \equiv 1 \pmod{N}\). The quantum part estimates it by
phase estimation and inverse QFT; the classical part derives the factors through rational
approximation and greatest common divisors, and verifies them.

The main instance is \(N = 15\), \(a = 7\), with eight control and four work qubits. Its
order is \(r = 4\), and the ideal control-register outcomes are 0, 64, 128, and 192. Each
measured execution, or \emph{shot}, returns a single outcome; many shots form the
histogram on which post-processing operates. Success means recovering non-trivial
factors, not reconstructing the exact order. Three of the four ideal peaks lead to it,
with an overall probability of 75\%. Classical verification is permissive, however: it
accepts 63 of the 256 values, so fully uniform outcomes would still succeed with
probability \(63/256 \simeq 24.61\%\). This reference depends on the instance and on the
post-processing, and does not measure the fidelity of the quantum state. It also shows
that correct factorizations can be obtained even when the distribution of the
control-register measurement outcomes has lost most of its ideal peak structure
\cite{en-smolin2013}.

Circuit correctness is verified independently of factorization success, by checking
modular operators, restoration of the ancilla qubits, and agreement with the theoretical
distributions. Besides \(N = 15\), the instances \(N = 21\), \(a = 2\) and \(N = 35\),
\(a = 6\) are considered; ideally validated, they use Beauregard's reversible arithmetic
\cite{en-beauregard2002}. Only \(N = 21\) enters the exploratory noisy AQFT tests, because
for \(N = 35\) the available hardware resources did not allow the simulation of an adequate
Shor circuit. Qiskit/Aer, scikit-learn, Stim, PyMatching, and ldpc are used, recording
versions, parameters, random seeds, and circuit identifiers.

\subsection{Sensitivity of Shor's algorithm to gate errors}

The starting point of the study was to measure how robust Shor's algorithm is to gate
errors. In the circuit of the main instance, compiled into the native gates RZ, SX, X, and
CX (depth 412, with 224 CX and 70 SX gates), independent Pauli errors are introduced after
every gate, except for the RZ rotations, which are virtual. The noise strength is set by
the probability \(p_{g}\) that a non-identity Pauli error occurs after a gate, varied over
13 values between 0 and 0.5.

The noise model is phenomenological and uniform and does not reproduce the calibration of
a real device. For this reason \(p_{g}\) should be read as a per-gate error probability:
it is not directly comparable with the logical failure probability \(p_{L}\) of the
error-correcting codes, because Shor's algorithm is not compiled in fault-tolerant form.

\subsection{Error mitigation through post-processing and machine learning}

The first strategy acts after measurement: without changing the circuit, it tries to
obtain the factors from noisy outcomes by choosing better which ones to verify, and it
assesses whether a machine-learning model makes this choice more effective. Three
selection strategies, sharing the same factor extractor and tie-breaking rule, operate on
the same histograms, one per quantum iteration, of 1,024 shots each. TOP-1 (Method~1)
checks only the most frequent outcome; TOP-4 checks up to four frequency-ranked
candidates; Method~2 applies TOP-4 only if a classifier predicts success for the dominant
candidate. The comparison between Method~2 and unfiltered TOP-4 is the ablation study,
which establishes whether the advantage comes from the learned model or simply from
testing more candidates.

Two illustrative scenarios, reference UC1 and stress case UC2, include depolarization,
thermal relaxation, and readout errors. For each scenario, 2,000 histograms with
parameters varied within \(\pm50\%\) of nominal are split 60\%/20\%/20\% into training,
selection, and test sets. Random forests, support vector machines (SVMs), and multilayer
perceptrons are compared on F1; the selected model is evaluated on 400 independent
histograms per scenario. The primary metric is the number of iterations needed to obtain
the factors; accuracy was treated as a secondary element in the study of the classifier,
while computation time was related to the available hardware resources. Thirty paired
replicates per scenario are used, with at most 50 iterations.

\subsection{Quantum error correction: surface code and qLDPC codes}

The second strategy protects the information before noise destroys it. In quantum error
correction, the information of one logical qubit is distributed across several physical
qubits; syndromes make it possible to detect errors without directly measuring the logical
state, and guide the decoder in choosing the correction. Performance is measured through
the logical failure probability \(p_{L}\).

Repetition and Steane codes serve as preliminary checks, while the main analysis concerns
memory circuits based on the surface code
\cite{en-steane1996,en-fowler2012,en-googleQECBelowThreshold2025}, with errors in gates,
preparation, and measurement and, in some configurations, crosstalk between adjacent
qubits. The reference decoder is \emph{minimum-weight perfect matching} (MWPM), which pairs
the triggered syndromes by choosing the most probable error configuration. MWPM is
compared with a stand-alone neural network and with a hybrid strategy, whose intervention
threshold is selected on the validation set and kept fixed on the test set
\cite{en-alphaqubit2024}.

An exploratory study also compares the surface code with IBM's Gross code, a quantum
low-density parity-check (qLDPC) code that encodes 12 logical qubits in 144 data qubits
\cite{en-bravyi2024}, in the code-capacity model, with errors on data qubits only and
perfect syndromes. BP+OSD (\emph{belief propagation with ordered statistics decoding}) is
used as an additional comparison decoder on the surface code and as the decoder of the
Gross code \cite{en-roffe2020}.

The comparison shows that the two approaches are not equivalent: for the same number of
logical qubits the Gross code requires far fewer data qubits, with an advantage that
depends decisively on the decoder (Section~\ref{sec:results-qec-en}).

\subsection{Noise reduction with the AQFT}

The third strategy reduces the effect of noise at its source, by lowering the number of
gates it can act on. The approximate QFT (AQFT) removes the small-angle controlled
rotations of the QFT, which contribute little to the phase information: the circuit loses
some precision but has fewer gates and lower depth, and therefore fewer opportunities for
error \cite{en-barencoAQFT1996}. The question is whether the noise avoided outweighs the
precision lost.

Truncation of Shor's final inverse QFT for \(N = 15\) and truncation of the transforms used
in the modular arithmetic for \(N = 21\) are analyzed separately; distinct phase-estimation
benchmarks, with registers of six to ten qubits, isolate the effect of truncation. The
noise model is built from the gate infidelities and readout errors of the offline
FakeSherbrooke calibration, without adding \(T_{1}/T_{2}\) contributions and keeping
layouts and random seeds unchanged. The truncation degree is selected on a dedicated set
and evaluated on independent test data; the shots per configuration, 8,192 in the
\(N = 15\) pilot and 256 for \(N = 21\), are split equally between selection and test.
